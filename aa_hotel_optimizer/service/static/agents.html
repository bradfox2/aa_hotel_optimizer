FOR AGENTS

A booking plan your agent can use.

Create a revocable key in My account → Agent access. Keys last 90 days and have search:read and optionally search:write scopes. Billing and connection management require the customer's browser session.

Submit, poll, compare

Use your app's origin as the base URL. Send the key in Authorization: Bearer YOUR_KEY. Read the complete request schema at /openapi.json.

POST /v1/searches
Authorization: Bearer YOUR_KEY
Idempotency-Key: a-new-unique-id-for-this-search
Content-Type: application/json

{
  "mode": "trip",
  "cities": ["Phoenix, Arizona"],
  "check_in": "2026-11-10",
  "check_out": "2026-11-14",
  "budget_cents": 120000,
  "objective": "value",
  "split_bookings": true,
  "max_hotel_changes": 0
}

Use future dates. A 202 response contains the search ID. Poll every three seconds; there is no benefit to polling faster. A retry with the same idempotency key and body returns the same search. A changed body requires a new key.

GET  /v1/searches/{id}
GET  /v1/searches
POST /v1/searches/{id}/cancel
GET  /v1/me

Respect action-required states

  • queued or running: keep polling.
  • browser_required or reauth_required: open the returned action_url for the customer. AA login stays in their browser.
  • completed: read the plans and warnings.
  • no_results: relax the budget or preferences.
  • failed: use error_code to adjust the next request. Do not blindly retry.
  • cancelled: stop polling.

A new search returns connection_required until the customer's browser is connected. Only one active search is allowed per account. Searches are bounded to 14 trip nights or 60 status-search nights and 400 city/date combinations.

Interpret the plan correctly

price_cents and cost_cents are integer USD cents. earned_lp excludes the starting balance; projected_lp includes it. miles are redeemable miles, a separate estimate. Dates use ISO format and check-out is exclusive. Each offer is one reservation, which may span several nights.

Inspect target_met, shortfall_lp, and complete_trip. All offered plans are estimates from observed quotes. Check observed_at; start a new search before relying on stale prices. No endpoint books or pays for a hotel.

Status searches and active promotions

Set mode: "status", starting_lp, and target_lp. You can search multiple cities. objective: "cost" uses exact minimum-cost selection when max_overlaps: 1; other status strategies are heuristics. Overlapping or no-show reservations do not guarantee rewards.

Only set policy.partner_bonus_percent when the customer has confirmed a registered, active bonus. Include bonus_start, bonus_end, and bonus_remaining. Never infer registration or eligibility from a projected LP balance.

Errors use {"detail": {"code": "...", "message": "..."}}. A 402 means the search allowance is exhausted; 429 means back off. Agent keys cannot buy membership.
